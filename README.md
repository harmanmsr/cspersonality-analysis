# Submission 2: Prediksi Response Campaign Marketing

Nama: Harman Muhammad

|                         | Deskripsi                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| ----------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Dataset                 | [Customer Personality Analysis](https://www.kaggle.com/datasets/imakash3011/customer-personality-analysis) — 2.240 data pelanggan retail dengan atribut demografis (`Income`, `Education`, `Marital_Status`, `Kidhome`, `Teenhome`), histori transaksi (`Recency`, `MntWines`, `MntMeatProducts`, dll.), perilaku pembelian per channel, dan histori penerimaan 5 campaign sebelumnya                                                                                                       |
| Masalah                 | Response rate campaign marketing historis rendah (rata-rata di bawah 15% per campaign). Mengirim campaign secara massal ke seluruh pelanggan menghasilkan biaya tinggi dengan konversi rendah, sehingga perusahaan perlu cara mengidentifikasi pelanggan yang paling mungkin merespons **sebelum** campaign diluncurkan                                                                                                                                                                   |
| Solusi machine learning | Model klasifikasi biner yang memprediksi probabilitas seorang pelanggan akan merespons (`Response = 1`) sebuah campaign, berdasarkan profil demografis dan histori transaksinya, sehingga budget marketing bisa ditargetkan ke pelanggan dengan probabilitas tinggi. Target performa: AUC ≥ 0.80 pada data evaluasi                                                                                                                                                                       |
| Metode pengolahan       | Cleaning (isi `Income` kosong dengan median, buang outlier usia >100 tahun dan income >99th percentile, standarisasi kategori `Marital_Status`) dan feature engineering (`Age`, `Customer_Tenure_Days`, `Total_Spending`, `Total_Children`, `Total_Purchases`) dilakukan sebelum masuk pipeline TFX. Di dalam komponen `Transform`: fitur numerik di-scale ke [0,1] (`tft.scale_to_0_1`), fitur kategorikal diubah jadi index vocabulary (`tft.compute_and_apply_vocabulary`)             |
| Arsitektur model        | DNN Keras: fitur numerik (26 fitur) digabung langsung, fitur kategorikal (`Education`, `Marital_Status`) melalui `Embedding` layer (dim=4) lalu di-flatten, seluruh fitur digabung → `Dense(units_1, relu)` → `Dropout(dropout)` → `Dense(units_2, relu)` → `Dense(1, sigmoid)`. Hyperparameter (`units_1`, `units_2`, `dropout`, `learning_rate`) dicari otomatis oleh komponen `Tuner` (KerasTuner RandomSearch, 10 trial, objective `val_auc`) sebelum training final oleh `Trainer` |
| Metrik evaluasi         | **AUC** (metrik utama, cocok untuk data imbalanced karena `Response=1` hanya ±15% populasi) dan **Binary Accuracy**, dihitung oleh komponen `Evaluator` menggunakan TensorFlow Model Analysis (TFMA) terhadap seluruh eval set                                                                                                                                                                                                                                                              |
| Performa model          | AUC 0.9116 dan Binary Accuracy 0.9184 pada eval set (429 contoh), dihitung TFMA dari model final hasil training dengan hyperparameter terbaik dari `Tuner`. Model dinyatakan *blessed* oleh `Evaluator` dan berhasil dipush oleh `Pusher` ke direktori serving                                                                                                                                                                                                                             |
| Opsi deployment         | Sistem dibungkus sebagai Docker image (base `tensorflow/serving`) dan dijalankan di **Railway**, dipilih setelah membandingkan beberapa platform: Heroku, Render, dan Hugging Face Spaces. Railway dipilih karena gratis (trial credit) tanpa kartu kredit di awal dan mendukung deploy langsung dari repo GitHub    |
| Web app                 | Model status: [cspersonality-analysis-production.up.railway.app/v1/models/marketing-response-model](https://cspersonality-analysis-production.up.railway.app/v1/models/marketing-response-model) — Prediction endpoint (POST): `.../v1/models/marketing-response-model:predict`                                                                                                                                                                                                          |
| Monitoring              | Prometheus (lokal, monitoring/docker-compose.prometheus.yml) meng-scrape endpoint /monitoring/prometheus/metrics bawaan TF Serving di Railway setiap 5 detik. Hasil: target tf-serving-marketing-model berstatus UP secara konsisten (up{job="tf-serving-marketing-model"} = 1), membuktikan endpoint monitoring TF Serving di Railway berhasil terpantau oleh Prometheus.        |
